# Qwen 接入与账号模型配置

日期：2026-10-09。实施与验收中的状态以验收记录为准。

用户要求通过 SSH 在实际服务器上部署可供线上面经服务使用的 Qwen，同时支持多租户、系统默认 Key 有限次数，以及用户自行配置 API Key / Base URL。用户已确认每账号默认 10 次。

## 行为约定

- 一个注册账号对应一个租户；服务端根据已认证的会话确定身份，不使用客户端提交的用户 ID 决定数据归属。
- 面经题库及原文作为共享知识库；对话、请求、复习记录、偏好、查询记忆和个人模型配置按账号隔离。
- 系统默认模型的额度为累计 10 次新 AI 提问，可通过部署配置调整。相同请求重试、SSE 重连、读取历史及确定性题库浏览不重复计次；准入后失败仍计次。
- 保存个人模型配置后，对话与相关性核验使用该账号的配置，不扣默认次数；删除配置后恢复原先剩余额度，不重置用量。
- API Key 加密保存，接口仅返回是否已配置；网页使用密码输入框，登录成功或保存完成后清空。账号及模型配置通过独立页面/对话框编辑。
- 查询向量使用题库原有 embedding 提供方及维度，以保持索引兼容；个人 Key / Base URL 改变对话和重排模型。共享知识库的导入、索引、分类发布仅供管理员执行。
- 现有匿名访问管理中的设备/IP封禁及限流继续有效；账号默认模型额度独立于可选的访客对话配额。

## 部署与验收

首先查看真实 GPU、磁盘、既有进程和模型服务；可复用已部署且通过认证、工具调用及流式验证的 Qwen，或部署独立用户服务。模型仅通过本机回环或私有连接访问。

为账号试用配置独立的默认模型 endpoint/key/model，原有语料抽取、embedding 及后台导入配置继续用于共享知识库。上线以当前 SSH 正式源码为基线叠加相关修改，保留当前 query v13 / rerank r14 及 corpus/index 293 的归属；不夹带本机其他检索实验。

验收覆盖：账号登录/退出、跨账号资源读取拒绝、个人配置密钥不回传、并发默认额度准入、幂等、默认额度用尽、个人 Key 绕过默认额度、个人配置失败不回退系统模型、真实 Qwen 对话/SSE、桌面与窄屏设置、正式服务/数据库迁移/源码哈希。备份正式数据库和受影响文件；回退保留新增表和迁移，不删除账号或会话数据。
