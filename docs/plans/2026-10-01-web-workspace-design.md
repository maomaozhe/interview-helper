# 面经 Web 操作台

目标：在现有本机 FastAPI 服务里提供可直接操作的中文界面，完成检索、问答、来源检查、复习记录、导入观察和问题收集。

沿用现有数据库、模型和检索服务。使用随 Python 包发布的 HTML/CSS/JavaScript，不增加前端构建服务。首页直接展示题库和操作控件。导航包含题库与检索、面经问答、导入与状态、问题记录。

检索可选择混合、关键词、语义和重排，支持主题、公司、轮次等现有筛选。空查询浏览真实高频题。详情展示标签、原始问法、真实频次、来源及复习操作。查询条件、执行方式、降级和请求编号收在可展开的排查信息里，支持复制。

导入页列出本地文件的生效状态及近期任务，可导入选定文件、导入新增/修改文件、同步索引和重试失败任务。页面只在用户点击时发起写操作。问题记录保存到共享 data/feedback，每条包含用户说明及当时的查询和题目上下文，可跨浏览器读取和导出。

所有原文按文本展示；链接仅允许 HTTP/HTTPS；文件访问沿用语料目录边界。请求有加载、失败、空结果和过期响应保护。界面适配窄屏，支持键盘和原生对话框。

验收：接口测试覆盖资源、路径边界、反馈持久化和统计口径；浏览器实际验证筛选、检索、详情、原文、复习、导入观察和问题记录；重建并启动现有 API，给用户可直接打开的本机地址。
