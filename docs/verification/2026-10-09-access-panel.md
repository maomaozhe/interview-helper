# 访问管理与运行看板验收

日期：2026-10-09。状态：已正式上线，发布后核验通过。规范：[访问管理 Spec](../plans/2026-10-09-access-panel-spec.md)。入口：[访问管理](https://interview.101-47-18-72.sslip.io/admin)。

## 功能与口径

新增独立 `/admin`，使用独立管理凭证与 HttpOnly 管理会话。支持近 1 小时 / 24 小时 / 7 天的真实设备数、IP 数、PV、业务请求、对话准入、拦截、当前 / 峰值 / 趋势 QPS、5xx 错误率和响应头 P95。访客可搜索和分页，设备与 IP 分别禁用、解除，配额可重置，操作原因与策略前后值保留审计。

Web 可以分别开启对话额度和 IP 查询限流、设置次数、选择每日 / 累计及设备 / IP 主体。初次正式上线默认两个开关关闭，预置每天 10 次、每 IP 每自然分钟 60 次。关闭时仍记录用量，开启或切换主体不会凭空清零。设备是签名 Cookie，不是实名自然人；IP 是网络出口，不是局域网设备地址。

自然语言 Query 与连续对话计一次准入，同一幂等请求恢复不重复扣减，准入后的模型失败也计次。直接检索和没有结果重放能力的旧 Chat 按实际调用计次。自动加载、结构化 SQL 列表、筛选、分页、历史、轮询和 SSE 重连不扣对话额度。请求指标保留 7 天，审计保留 30 天，累计配额单独持久化。

## 验收中发现并修复

1. 正式两层 Caddy 原配置会把来源 IP 变成回环地址。使用隔离双代理验证内层严格信任回环代理、外层去除伪造头的方案，API 关闭 Uvicorn 自动代理头解析，由应用识别可信来源链。
2. 管理页使用根路径 `<base>` 时，片段相对 URL 导致切栏目后地址变成工作台根路径，刷新退出管理页。历史地址改为显式保留当前 pathname，跳转主要内容链接也指向管理页，浏览器切换 / 刷新复验通过。
3. 工作台初始化会自动 POST 结构化 SQL 列表，最初消耗了对话额度，设为 1 时首个用户问题就被拒绝。修正为仅自然语言和模型检索准入计次；增加真实 HTTP 启动回归，验证连续多次 SQL 浏览用量为 0，首问通过、第二问 429，达到上限后 SQL 浏览仍可用。
4. 策略修改采用版本比较；额度重置确认时冻结策略版本，提交时再次检查，防止其他管理员将设备主体改为 IP 后误重置共享出口。
5. 管理 JSON 禁止缓存，登录校验错误不回显 token；代理 HTTPS 会话保留 Secure。设备 / IP 封禁不能阻断管理恢复和内部 Agent 通道。
6. SSE 在响应头建立时记录指标，避免等整个生成结束才出现在 QPS；P95 明确为响应头耗时，不能理解为模型完整生成时间。
