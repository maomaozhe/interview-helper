# Agent 工作方式：记录、核查、决策、验证

适用于本仓库的调查、实现和故障处理。目标是留下可接续的事实与决策依据，让后续 Agent 知道已经试过什么、还缺什么。入口约定见 [AGENTS.md](../../AGENTS.md)，旧坑见 [复盘索引](../retrospectives/README.md)。

## 先留下最小工作记录

开始非简单任务、首次修改实现之前，先在已有任务计划或问题条目中写下以下内容；没有合适记录时在 `docs/plans/` 建短记录。故障过程优先追加 `md/issue.md`，复用已有条目和编号。记录可短至几行，不要求每个小改动另建文件。

| 字段 | 最少应包含 |
| --- | --- |
| 目标与边界 | 要修什么、验收什么、用户约束及本轮修改范围 |
| 已知事实 | 观察到的输入/症状、环境、代码与数据身份、对应日志/回执 |
| 待验证假设 | 可能原因及为什么值得检查；没有证据的不写成根因 |
| 下一步检查 | 哪个低成本检查可以区分这些假设，成功/失败信号是什么 |

纯文案或路径修正也先定位依据并记明改动意图；任务回复或现有记录足以说明时，无需另外生成计划文件。
业务代码、配置、语料和个人状态是不同修改范围；开始前检查工作区已有变更，并保留它们。

## 用事实收敛原因，再选择方案

1. 查 [知识库导航](../README.md) 和相关 PIT 专题，确认已有契约及失败尝试。
2. 从真实入口、当前源码字段、运行装配和输入身份核查，不猜路径、数据库列、模型名称或部署版本。
3. 把“现象”“假设”“证实原因”分开。接口失败、模型失败、检查器错误和语义错误不能混成同一种失败。
4. 优先用只读检查、确定性重放或小范围测试区分原因；需要外部调用时沿用已授权范围、预算和共享锁。
5. 在实施前记录选中的方案、简要理由、主要代价、验收条件；确有竞争方案时说明为何取舍。

这里保存可复核的事实、假设、方案和简要理由即可。不要把大段推演替代证据，也不要要求记录每一步内部思考。

## 每次失败先记录，再决定是否重试

在下一次尝试前保留：操作、时间/环境、可用错误码、关键输入身份、实际结果、已消耗调用/预算及相关证据路径。优先保存第一现场，避免后续重试覆盖。

- 相同输入反复失败且没有新证据时，先更新假设或缩小检查，不能把重试当作定位。
- 格式/ID/引文错误与网络/配额错误有不同恢复方式；保留最后有效草稿或检查点，不降低原有业务校验。
- 不能通过隐藏失败、放宽断言、改参考标签或抬高预算把失败改写为成功。
- 来源不足时写“未知”；若是检查器或传输问题，单独记录，不算成模型语义失败或通过。

有在途调用或未知 usage 时保留不确定性，避免续跑时把预算重置为零。重放和恢复沿用请求身份与幂等规则。

## 实施后按预先条件验证

选择与变更对应的测试和真实入口，分别记录工程检查、业务断言、语义审核与部署核验。说明命令、数据/环境、结果、跳过项和仍未覆盖范围。

验证失败时回到“事实与假设”，保留本次结果后再决策。代码修改、参数选择、安装包更新与线上部署分别取证；代码存在或测试通过不代表另一个环境已启用。

需要中断或交接时更新最小检查点：已经完成的步骤、有效产物、失败尝试、预算/请求身份、当前阻断与下一步。后续 Agent 先读记录再继续，避免重做成功步骤或重复外部写入。

## 将有复用价值的结果沉淀

有复用价值的问题关闭或缓解时，按需沉淀三类信息：

1. 在原条目追加处理结果及验证依据，保留历史过程。
2. 按根因更新已有 PIT 专题；新根因再建篇，补失败尝试、解决过程、范围与防复发措施。
3. 同步复盘索引及 [来源映射](../retrospectives/SOURCE-MAP.md)；稳定契约进 [invariants](invariants.md)，长期取舍进 `decisions/`，当前能力变化才更新 `status/current.md`。

防复发措施分别标明“已有测试/规则”“待补测试/机制”“仅有操作建议”。未执行的方案不能写成有效措施，未解决问题继续保留 open/mitigated/reopened。

任务完成后检查临时计划是否仍有独立价值：纯施工步骤删除，当前规则并入对应知识页，独有选择与取舍保留在 decisions，真实失败和验收证据继续保留。不要把同一结论复制到计划、状态页、复盘和完成报告四处；需要时用链接。最小复盘格式见 [新增与维护](../retrospectives/README.md#新增与维护)。

## 可直接追加的短记录

```text
目标/范围：
已知事实与证据：
假设及待区分点：
下一步检查与预期信号：
选择方案与简要理由：
本次尝试及实际结果：
验证、剩余问题与下一步：
关联 PIT / 原条目 / 产物：
```

记录里引用必要证据即可，不复制凭据、个人会话或私有来源全文。旧记录按原始时间保留；新证据改变结论时追加说明并链接，不覆盖旧失败。
